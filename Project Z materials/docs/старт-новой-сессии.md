# Старт новой сессии

Вставьте текст ниже первым сообщением в новой сессии (модель Opus 5.5, рабочая папка `C:\Project Z materials`).

---

Продолжаем Project Z. Прочитай `концепт.md`, `сюжет.md`, `docs/art-direction-brief.md`, `docs/asset-manifest.json`. Используй скиллы `pixel-art-sprites` и `create-game-assets`.

Состояние: герой Владимир Чернов (`hero-idle`, `hero-walk`, `hero-run`; 8 направлений, 64×96, складки, скелетная SDF-модель) нарисован пайплайном `tools/hero_render.py` → `tools/aseprite_build_hero.lua`, статус `review`. Тестовая арена Godot: `C:\project Z\z\scenes\test_arena.tscn` (960×540 ×2, камера −30°, 1 м = 56 px, WASD, Shift — бег, C — толпа).

Мокап: `tools/mocap.py` переносит BVH (CMU, github sfd158/cmu-mocap, data/002, swordplay 02_07–02_09) на скелет героя. Для фирменных ударов лучше ключевые позы вручную (замах, удар, возврат).

Боевые анимации (`tools/attacks.py`, статус `review`): blade_quick, blade_heavy, sickle_quick, sickle_heavy, gun_aim, gun_shoot_r, gun_shoot_l. В арене: 1–4 удары (повтор — продолжение серии), F — выстрел.

Mixamo: скачивание через внутренний API сайта в сессии пользователя (`playwright-cli -s=mixamo`, Edge, постоянный профиль; пользователь входит сам). Формат Collada `dae_mixamo`, без скина, 30 fps; загрузчик `tools/mixamo_dae.py`. При ошибке 429 делать паузы 20–45 с между экспортами.

Герой в игре — три слоя (`tools/hero_layers.py`, `art/hero/layers/`): ноги, корпус с модулем (клинок, серп, обрез), левая рука с револьвером. Холст слоёв 128×128. Управление в арене: WASD — бег, мышь — прицел (наведение на врага целит в него), ЛКМ — лёгкая, ПКМ — тяжёлая (после двойного прыжка — удар о землю), Alt — револьвер, Shift — рывок, Space — прыжок (дважды), Ctrl — ульта (у серпа зажать и отпустить), R — перезарядка, Q — смена оружия. Проверка без окна: `godot --headless --path . -s res://tests/test_round17.gd` (и `test_round3.gd`–`test_round16.gd`). Лежащие трупы — спрайты на плоскости пола (`gore.gd`, `_lay_on_floor`). HUD в верхнем левом углу, вместо курсора прицел. HUD — `tools/hud_gen.py`, `scripts/hud.gd`; звуки — `tools/sfx_fetch.py` (`search группа,группа` пересобирает только эти группы, `EXCLUDE` — отвергнутые записи), `scripts/sfx.gd`, `assets/audio/CREDITS.md`. Стонов и криков врагов нет по решению пользователя. Импорт в Godot запускать без обрезки вывода; `.import` не создавать вручную. Последние правки: `правки/ПРАВКИ.md`.

Противник-человек с расчленёнкой (`tools/enemy_render.py`, `art/enemy/`), эффекты (`tools/fx_gen.py`, `art/fx/`), кровь и куски в Godot — `scripts/gore.gd`. Динамическое разрешение и F11 в арене.

Дальше по решению пользователя: кровь на оружии героя, кадры старта/остановки, уклонение, атаки противников, механоиды.

Aseprite из PowerShell запускать через `Start-Process -Wait`, иначе команда не дожидается окончания.
