## Последовательность и привязки

Контракт: `art/mech/mech_death.json`; полные метаданные рядом в `mech_die.json`, `mech_die_decap.json`, `mech_shatter.json`, `mech_wreck.json`, `mech_pilot_head.json`.

1. Гибель пилота и кровь — кадр 0. Для decap отделяется голова.
2. Наклон и дым — шесть поз, длительности 100/140/180/220/260/160 мс; дым запускается с кадра 2, через 240 мс.
3. Взрыв — кадр 5, через 900 мс. С этого кадра пилота в спрайте нет.
4. После 1060 мс — два кадра распада по 80/100 мс.
5. После 1240 мс — неподвижный обгоревший остов, дым остаётся отдельным эффектом.

Pivots: смерть (128,218), распад (128,200), остов (128,128). Разница намеренная: распад и лежащие узлы занимают больше места под точкой опоры. При размещении использовать метаданные.

Остов подготовлен для пола по существующему `gore.gd::_lay_on_floor`: billboard выключен; Basis с yaw 45°, поворотом X −90° и растяжением Y ×2 компенсирует камеру 30°. PNG уже содержит проекцию; не растягивать сам файл дополнительно. Фактическая сортировка и размещение в Godot относятся к этапу 5.
