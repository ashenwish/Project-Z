## Воспроизведение

Служебные проходы как раньше, из Blender с открытым мехом:

```python
ANIM, DIRS = "hit", ["s", "se", "e", "ne", "n", "nw", "w", "sw"]
exec(open(r"D:/PRZ/Project Z materials/tools/mech_blender.py", encoding="utf-8").read())
```

Для каждого из `piece_cover`, `piece_shield`, `piece_cap` достаточно `DIRS = ["s"]`: кувырок не привязан к направлению меха, как P_ противников. Рендерить на исходной сцене без активных ключей из сцены просмотра. Для проб допускается отдельный `OUTD`.

Из папки материалов:

```powershell
python tools/mech_render.py hit
python tools/mech_render.py piece_cover s
python tools/mech_render.py piece_shield s
python tools/mech_render.py piece_cap s
python tools/mech_damage_sheets.py
```

Сцена просмотра создаётся отдельно:

```powershell
& 'C:/Program Files/Blender Foundation/Blender 5.2/blender.exe' --background 'art/mech/Untitled.blend' --python-exit-code 1 --python tools/mech_damage_scene.py -- 'art/mech/mech_scout_damage.blend'
& 'C:/Program Files/Blender Foundation/Blender 5.2/blender.exe' --background 'art/mech/mech_scout_damage.blend' --python-exit-code 1 --python tools/test_mech_damage_scene.py
```

Фактические проверки этой сессии выполнялись в `D:/Projects/PRZ-stage2` на сохранённой копии открытой сцены. Там сохранены резервные копии исходников, исходная сцена и логи рендера/проверок. Модель, текстура, палитра, ходьба и прежние якоря не заменялись.
